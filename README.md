# STARDEV COMMUNITY | LULU — Claude Skill

A Claude Skill designed to help Claude understand how to create **ready-to-run Roblox scripts** using the built-in **Lulu UI v1.4.0** library, with a focus on Delta and other compatible script executors.

## Installation Guide

1. Download the `lulu-script-builder.zip` file.
2. Open [Claude](https://claude.ai/) and sign in to your account.
3. Go to **Settings**.
4. Navigate to **Capabilities** or **Skills**, depending on your Claude interface.
5. Select **Add** or **Upload a skill**.
6. Upload the downloaded ZIP file and wait for the process to complete.
7. Enable the skill if necessary.

## What's Included?

- **Lulu UI v1.4.0** — Uses the built-in UI library when generating scripts.
- **Script Builder** — Helps Claude generate structured, ready-to-run Roblox scripts.
- **Executor Compatibility** — Focuses on Delta and other compatible executors, subject to API and environment support.
